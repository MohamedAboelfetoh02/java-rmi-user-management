# java-rmi-user-management
Distributed Java application built with RMI to perform remote CRUD operations and client-server communication.

## Overview
This project is a distributed Java application built using Remote Method Invocation (RMI). It allows a client to communicate with a remote server and perform user-management operations.

## Features
- Remote client-server communication
- User CRUD operations
- Arithmetic methods
- Object-based processing
- Remote interface design

## Technologies
- Java
- Java RMI
- NetBeans
- Ant

## Learning Outcomes
- Distributed systems concepts
- Serialization and remote objects
- Java networking
- Client-server architecture
